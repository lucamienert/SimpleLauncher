# SimpleLauncher

A fast, minimalist Android home launcher built with Kotlin and Jetpack Compose (SDK 37).

## Features

* **Clean Home Screen:** Live clock, date, and 1–7 customizable favorite apps.
* **Universal Search & App Drawer:** Search installed apps, contacts, and the web (DuckDuckGo by default).
* **Zero Clutter:** Dark mode, distraction-free vertical layout, and no internet permission required.

## Gestures

* **Swipe Up** (or tap search bar): Open App Drawer & auto-focus search
* **Swipe Down**: Expand Android Notification Shade (or close App Drawer)
* **Swipe Left**: Open default Browser
* **Swipe Right**: Open Phone dialer

## Build & Install

**Debug:**
```bash
./build.sh
```
